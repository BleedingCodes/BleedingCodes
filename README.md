# Hey, I'm Michael

I'm an electronics technician who experiments with Python and AI to build tools that are actually useful.
Most of what's here started because I needed it at one point or another.
Some of it is just me exploring ai and python because I like knowing how things work under the hood.

Everything runs on Linux. Everything is Python.

## What's Here

| Repo | What it does |
|---|---|
| [microcam-benchscope](https://github.com/BleedingCodes/microcam-benchscope) | PCB inspection workstation — HDMI microscope, OCR, measurements, focus stacking, HDR |
| [sftp-ultra](https://github.com/BleedingCodes/sftp-ultra) | SFTP engine built for production — concurrent workers, SHA-256 verification, SQLite journal |

| [PureTrace](https://github.com/BleedingCodes/PureTrace) | CPU-only path tracer in pure Python — physically-based materials, zero dependencies |

| [rd-idea-engine](https://github.com/BleedingCodes/rd-idea-engine) | R&D research and stress-test tool — three versions: browser (OpenAI), CLI (Anthropic), local (Ollama) |

| [matrix-rain](https://github.com/BleedingCodes/matrix-rain) | Matrix-style live wallpaper — pygame, X11/xwinwrap, CLI configurable |
| [bleedingtones](https://github.com/BleedingCodes/bleedingtones) | Terminal audio triggers for builds, scripts, and CI hooks |
